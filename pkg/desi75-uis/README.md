desi75-uis
==========


Presentation
------------

*desi75-uis* is the static web-server of the web-app *desi75-ui*.


Requirements
------------

- [node](https://nodejs.org) > 20.10.0
- [npm](https://docs.npmjs.com/cli) > 10.1.0


Installation
------------

```bash
npm i -D desi75-uis
```


Usage
-----

```bash
npx desi75-uis
npx desi75-uis --help
```


Usage without installation
--------------------------

```bash
npx desi75-uis
npx --package=desi75-uis desi75-uis
npx --package=desi75-uis desi75-uis --help
```


Development
-----------

```bash
git clone https://github.com/MYNAME/parame75
cd parame75
npm install
npm run ci
npm -w desi75-uis run run
```
