desi75-cli
==========


Presentation
------------

*desi75-cli* is a *command line interface* application for presenting the designs of *desi75*.


Requirements
------------

- [node](https://nodejs.org) > 20.10.0
- [npm](https://docs.npmjs.com/cli) > 10.1.0


Installation
------------

```bash
npm i -D desi75-cli
```


Usage
-----

```bash
npx desi75-cli
npx desi75-cli --help
```


Development
-----------

```bash
git clone https://github.com/MYNAME/parame75
cd parame75
npm install
npm run ci
npm -w desi75-cli run run
```
